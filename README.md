# AI Career Boost

Ready-to-deploy AI Resume & Job Application Assistant.

Features:
- Email/password accounts
- 5 free AI generations
- Resume, cover letter, resume improvement and skill matching
- Pro plan UI at ₹299/month
- Optional Razorpay subscription checkout
- SQLite database
- Mobile-friendly UI
- Replit-ready

## Replit
1. Import this ZIP into a new Replit app.
2. Add Secrets: OPENAI_API_KEY and a strong JWT_SECRET.
3. Optionally add RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET and RAZORPAY_PLAN_ID.
4. Run `npm start`.
5. Deploy.

Before accepting public payments, add payment webhooks/status synchronization, rate limiting, security headers, email verification/password reset, privacy/terms/refund pages, and production database/backups.

Never put API keys in frontend code or GitHub. Users should review all AI-generated application materials before submitting.
